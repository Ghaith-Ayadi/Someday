# Genesis

Starter template: Vite + React + Untitled UI.

## Create a new project

Give this to Claude from your new project folder in VSCode:

```
Run `gh repo create <NAME> --private --template Ghaith-Ayadi/Genesis --clone` to scaffold this folder from the Genesis template. Then cd into the project, run `npm install` inside untitledui-vite-starter-kit/, update index.html title and meta description, and run `npm run dev` to start the dev server. Project name: <NAME> — Description: <DESCRIPTION>
```
